## Operating Thesis

Most software projects are built to solve one problem once.
I build systems that compound.

**Automation compounds** — a workflow built correctly runs itself, improves over time, and creates leverage that scales without headcount.

**Quantitative systems compound** — rigorous research infrastructure, properly documented, becomes an asset that generates returns across every subsequent analysis.

**Education tooling compounds** — a well-designed learning system teaches one student today and ten thousand students over its lifetime without degrading.

**Robotics simulation compounds** — autonomous mission systems trained in simulation transfer to production environments with lower cost and higher reliability than hardware-first approaches.

The goal is not to write code. The goal is to build systems with increasing returns — software, automation, research infrastructure, and organizational tools that get more valuable over time, not less.
